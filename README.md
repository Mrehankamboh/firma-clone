# Firma

Self-written clone of [firma-template.framer.website](https://firma-template.framer.website/). HTML, CSS, and a small script. No Framer runtime.

Desktop is a horizontal track at 1440×900. Below about 860px the page stacks.

## Run

```bash
npx serve -l 4173 .
```

Open [http://127.0.0.1:4173/](http://127.0.0.1:4173/). After a CSS or JS change, hard-refresh with Ctrl+F5.

## Pages

- Home: `index.html`
- Work, Studio, Journal, Contact
- Case studies under `work/`
- Articles under `journal/`
- Privacy, Terms, 404
